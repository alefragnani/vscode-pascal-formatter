## Formatlaşdırma mühərrikini seç

Pascal Formatter xarici formatlaşdırma alətləri ilə inteqrasiya olunur. Kodu formatlaşdırmaq üçün əvvəlcə onlardan birini quraşdırmalısan.

Aşağıdakı mühərriklər dəstəklənir:

| Mühərrik | Platforma | Seçilmiş hissəni dəstəkləyir |
|--------|----------|--------------------|
| **Jedi Code Format** | Yalnız Windows | Xeyr |
| **Jedi Code Format (Quadroid)** | Windows, Linux, macOS | Xeyr |
| **FreePascal PToP** | Windows, Linux, macOS | Bəli |
| **Embarcadero Formatter** | Yalnız Windows | Xeyr |
| **pasfmt** | Windows, Linux, macOS | Xeyr |
