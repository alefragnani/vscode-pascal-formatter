## Escolha uma Ferramenta de Formatação

O Pascal Formatter integra-se com ferramentas externas de formatação. Você deve instalar uma delas antes de formatar o código.

As seguintes ferramentas são suportadas:

| Ferramenta | Plataforma | Suporta Seleção |
|------------|------------|-----------------|
| **Jedi Code Format** | Somente Windows | Não |
| **Jedi Code Format (Quadroid)** | Windows, Linux, macOS | Não |
| **FreePascal PToP** | Windows, Linux, macOS | Sim |
| **Embarcadero Formatter** | Somente Windows | Não |
| **pasfmt** | Windows, Linux, macOS | Não |
