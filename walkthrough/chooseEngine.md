## Choose a Formatter Engine

Pascal Formatter integrates with external formatting tools. You must install one before you can format code.

The following engines are supported:

| Engine | Platform | Supports Selection |
|--------|----------|--------------------|
| **Jedi Code Format** | Windows only | No |
| **Jedi Code Format (Quadroid)** | Windows, Linux, macOS | No |
| **FreePascal PToP** | Windows, Linux, macOS | Yes |
| **Embarcadero Formatter** | Windows only | No |
| **pasfmt** | Windows, Linux, macOS | No |
