## Jedi Code Format (Quadroid)

**Platform:** Windows, Linux, macOS

**Supports selection formatting:** No (full document only)

### Step 1 — Download and Install

[Download JCF (Quadroid)](https://github.com/quadroid/jcf-pascal-format)

Extract the archive and note the location of the `jcf` executable.

### Step 2 — Configure the Extension

Add the following to your settings:

```json
{
    "pascal.formatter.engine": "jcf-quadroid",
    "pascal.formatter.enginePath": "C:\\tools\\jcf\\jcf.exe"
}
```
